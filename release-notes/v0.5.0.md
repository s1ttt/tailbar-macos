# Tailnet Bridge v0.5.0 — public preview

An unofficial Apple Silicon macOS menu bar interface for a separate Homebrew
`tailscaled` daemon. This first public release includes the app, source, and
optional scripts for local HTTP CONNECT bootstrap and a specific INCY TUN
exit-node routing setup.

## Highlights

- Connect/disconnect, device search, exit-node selection, account state, and diagnostics.
- A small top-left status dot shows whether INCY/Happ is running without a
  local listener (amber) or a local proxy port is available (green).
- The Dock icon has a permanent green dot to distinguish it from the official app.
- Direct connection is allowed when no local listener is found.
- Quit closes the interface without stopping `tailscaled`.

## Install

1. Install Homebrew `tailscale` and start its daemon with
   `sudo brew services start tailscale`.
2. Download the macOS ARM64 ZIP and matching `.sha256` file attached below.
3. Run `shasum -a 256 -c TailscaleMenuBar-v0.5.0-macos-arm64.zip.sha256`.
4. Unzip and move `TailscaleMenuBar.app` to Applications.

See the [installation guide](https://github.com/s1ttt/tailnet-bridge-macos/blob/main/docs/INSTALL.md)
for full steps, source builds, optional services, and rollback. The binary is
ad-hoc signed but not Apple-notarized. It targets Apple Silicon macOS 15+.

The optional route helper is IPv4-only and specific to INCY TUN at
`198.18.0.2`. A green listener dot is not an internet or exit-node test.
