# Tailnet Bridge v0.6.0 — sleep and network recovery

With INCY or Happ and a Tailscale exit node, the Mac could end up with Wi-Fi
connected and no internet. This happened after the lid closed, after moving
from a phone hotspot to home Wi-Fi, after quitting INCY, or after turning an
exit node off. The only way out was to quit everything and toggle Wi-Fi.
Tailnet Bridge now handles these cases itself.

## Highlights

- **Sleep and wake** (on by default):
  - Before sleep, Tailscale is stopped so its routes cannot trap the client's
    own connection.
  - After wake, the app waits for Wi-Fi and INCY/Happ, then reconnects with
    the same exit node and checks it with `tailscale ping`.
  - A phone hotspot that needs joining by hand is fine: the app waits as long
    as it takes.
- **Network health and repair** (on by default). The app watches for:
  - a missing default route;
  - a route into a dead tunnel;
  - DNS left pointing at INCY or Tailscale;
  - an exit node that stopped answering;
  - no internet.

  It repairs these the way you used to by hand: stop Tailscale, restart Wi-Fi,
  wait for INCY/Happ, restore Tailscale. It makes at most two automatic
  attempts, then sends one notification.
- **Reconnect Tailscale** and **Repair Network** in the menu bar menu, in
  Settings, and in Diagnostics.
- Reconnecting now restores the selected exit node reliably. The old lookup
  never matched it.
- The optional INCY TUN route helper:
  - holds its `/1` routes back for 20 s after a wake;
  - restores a missing default route from the Wi-Fi gateway.

Internet reachability is checked with an HTTP request to `captive.apple.com`,
the URL macOS itself uses. Turning off automatic repair in Settings stops it.

## Install or upgrade

1. Download the macOS ARM64 ZIP and matching `.sha256` file attached below.
2. Run `shasum -a 256 -c TailscaleMenuBar-v0.6.0-macos-arm64.zip.sha256`.
3. Quit the running Tailnet Bridge, unzip, and replace
   `/Applications/TailscaleMenuBar.app`.

If you installed the optional route helper, reinstall it to get the new wake
and default-route handling (see INSTALL.md). The app itself still needs no
administrator rights.

See the [installation guide](https://github.com/s1ttt/tailnet-bridge-macos/blob/main/docs/INSTALL.md)
and [networking notes](https://github.com/s1ttt/tailnet-bridge-macos/blob/main/docs/NETWORKING.md).
The binary is ad-hoc signed but not Apple-notarized. It targets Apple Silicon
macOS 15+. This project is independent of and not endorsed by Tailscale,
INCY, or Happ.
